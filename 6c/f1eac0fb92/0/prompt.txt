**Key commands:**
- `make lint` — ESLint across all `code-apps/*/`
- `make test` — unit tests across all `code-apps/*/`
- `make build` — build all `code-apps/*/`
- `make validate` — lint + pac solution pack structural check
- `pac solution pack --folder solutions/<name> --zipfile <output>.zip --processCanvasApps`
- `pac solution unpack --zipfile <input>.zip --folder solutions/<name>`
- `pac code push` — deploy a code app
- `pac auth create` — authenticate PAC CLI to an environment

**Deployment:**
- Dev environment: local `pac auth` (developer's own)
- Production: automated via `.github/workflows/deploy-solution.yml` (OIDC, no long-lived secrets)
- **Never run** `pac solution import` against production manually

**Boundaries (3-tier) to encode:**

- Keep connection references and environment variable values in `solutions/<name>/deployment-settings.json`

- Keep generated TypeScript under `src/generated/` untouched — always regenerated by connector skills
- Use the project orchestrator skill that matches the task area (listed above)
