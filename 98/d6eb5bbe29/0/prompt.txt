Please use 'copilot plugin update' to update the outdated ones - "copilot plugin update --help
Usage: copilot plugin update [options] [name]

Update a plugin to the latest version, or update all installed plugins.

Fetches and installs the latest version of previously installed plugins.

Arguments:
 name Plugin name (plugin-name@marketplace-name); omit when using --all

Options:
 --all Update all installed plugins
 -h, --help display help for command

Examples:
 # Update a marketplace plugin
 $ copilot plugin update spark@copilot-plugins

 # Update a directly installed plugin
 $ copilot plugin update my-plugin

 # Update all installed plugins
 $ copilot plugin update --all
